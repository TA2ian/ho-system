Campaign API\n\nCampaigns model the operational advertising relationship. Customer gross amount, planned ad spend, management fee, and advertiser profit-share terms are stored as campaign terms; invoices and payments remain the financial source of truth. Advertising spend is recorded manually because no ad-spend provider API is assumed.\n\nAdvertiser access is scoped to campaigns assigned to that advertiser. Employees do not receive campaign profit shares through this module.\n\nEndpoints: GET /api/v1/campaigns, GET /api/v1/campaigns/:id, POST /api/v1/campaigns, POST /api/v1/campaigns/:id/status, POST /api/v1/campaigns/:id/invoices, POST /api/v1/campaigns/:id/spend.
